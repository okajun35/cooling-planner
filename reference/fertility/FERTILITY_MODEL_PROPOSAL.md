# Cooling Planner 受胎モデル：調査結果と仕様案 v0.7

作成日：2026-09-26  
モデルID：`fertility-thi-period-or-baccouri2025-v1-proposal`  
状態：**採用案・未承認。独立した参照計算と単体テストは実行済み。既存アプリへは未統合。**

## 1. 調査の結論

温湿度と乳牛の受胎成績の研究はあり、公開された係数から参考値を計算できる。初版の採用案はBaccouriら（2025）の期間別THI区分・オッズ比を使うカテゴリー参照モデルとする。[S1]

モデルが扱うのは人工授精1回に対して後日妊娠が確認される割合の参考値であり、精子と卵子の受精そのものの確率、21日妊娠率、分娩率ではない。実際の個体の妊娠診断や、設備の因果的な効果の保証には使わない。

この文書は既存v0.6のR01を閉じるための採用案であり、ユーザーによる仕様承認を記録したものではない。既存の乳量表の補間禁止、熱計算60分、実農場検証を完成条件にしない決定を変更しない。

## 2. 確認した一次研究

| ID | 文献 | 確認内容と扱い |
|---|---|---|
| S1 | Baccouri et al., 2025, Animals 15:2001 | ハンガリー南部1農場、2002–2024年、6,751頭・47,199件の人工授精。本文の方法2.2–2.4とTable 2を確認。期間別カテゴリー係数を採用する。 |
| S2 | Nabenishi et al., 2011, J Reprod Dev 57:450–456 | 日本南西部170群・11,302頭の初回人工授精。本文とTable 1–3を確認。分娩で受胎を確認する定義なのでS1の係数と混ぜない。 |
| S3 | Schüller et al., 2014, Theriogenology 81:1050–1057 | 公開抄録を確認。授精前21〜1日の平均THIが73以上のとき受胎率31%から12%と報告。期間が重要であることの補助根拠。今回の係数には不採用。 |
| S4 | Hagiya et al., 2017（オンライン2016）, Anim Sci J 88:3–10 | 公開抄録を確認。国内47都道府県の気象を利用し、夏〜初秋の授精と暑熱地域で受胎成績低下を分析。228,242件は乳生産・体細胞数等も含む記録であり、人工授精件数と言い換えない。 |
| S5 | Nishisozu et al., 2023, J Reprod Dev 69:72–77 | 公開抄録と本文を確認。245農場、ホルスタイン未経産1,407頭・経産3,189頭への黒毛和種IVP胚移植。経産牛で気温25℃超・THI75超と低受胎成績の関係。人工授精ではなく胚移植なので、今回の係数には不採用。 |

S2の具体例：授精2日前・前日・当日の最大THIがすべて80以下の群は38.1%（3,621/9,500）。前日だけ80を超え、他2日は80以下の群は25.0%（20/80）。これは当該曝露パターンの群比較であり、「一律にTHI80超なら25%」と一般化しない。最大THIは日最高気温と日最低湿度から計算され、S1の期間平均THIと同一視しない。[S2]

## 3. 採用する原研究の枠組み

S1の妊娠は概ね授精40〜45日後の直腸検査で確認される。40〜100日後の陰性診断、または100日以内の再発情による不成功判定も含む。気象は農場から13kmの観測所の日別値であり、牛体温や冷却機器の実験ではない。[S1]

### 3.1 THIとカテゴリー

S1の式をそのままモデル内で使う。Tは℃、RHは0〜100の百分率。

```text
THI = (1.8*T + 32) - (0.55 - 0.55*RH/100)*(1.8*T - 26)
```

| 区分コード | 期間平均THI | UI上の仮ラベル |
|---|---|---|
| none | THI < 60 | 基準区分 |
| small | 60 <= THI < 68 | 軽度区分 |
| medium | 68 <= THI < 72 | 中等度区分 |
| severe | THI >= 72 | 高暑熱区分 |

これは文献が定めた区分の参照であり、未掲載の中間値を補間したものではない。区分境界に表示丸めは使わない。別の文献や既存熱モデルのTHI式に、係数だけを無条件に流用しない。[S1]

最外側の区分に入る全温度で精度が確認されたことは意味しない。例えばTHI72と84は同じ区分を参照するが、84での受胎率が独立に実証済みという意味ではない。高暑熱区分内のさらなる悪化や、極端な寒冷の影響は計算しない。原研究の実測最小・最大値を推測して境界値として記載しない。

### 3.2 期間とオッズ比

授精日を0日とする。各区間は両端を含む。合計52日間を5期間に区分する。[S1]

| 期間 | 日の範囲 | 基準 | 軽度 | 中等度 | 高暑熱 |
|---|---|---:|---:|---:|---:|
| P1 | -21〜-6 | 1 | 0.823 | 0.697 | 0.773 |
| P2 | -5〜-2 | 1 | 0.973 | 0.913 | 1.005 |
| P3 | -1〜+1 | 1 | 0.926 | 0.887 | 0.693 |
| P4 | +2〜+7 | 1 | 0.941 | 0.935 | 0.922 |
| P5 | +8〜+30 | 1 | 1.058 | 0.941 | 0.854 |

出典：S1 Table 2。率の倍率ではなく、成功オッズの倍率である。

有意差が報告されたのはP1の各暑熱区分、P3とP5の高暑熱区分であり、P2・P4は有意差なし。ただし、この再利用案では係数を都合よく1へ変えず、全固定効果を掲載どおり保持する。有意差のない係数を「効果が確定している」と説明しない。[S1]

P1の中等度と高暑熱の大小逆転など、単調でない掲載値も保持する。これは観察データの回帰係数であり、冷却を強めればあらゆる期間の出力が必ず改善するモデルではない。見栄えのための平滑化や並べ替えはしない。

## 4. アプリが追加する仮定と式

### 4.1 基準確率

すべての期間が基準区分だった場合の仮想基準受胎率 `p0=0.40` をデモ値として置く。日本の平均値、当該研究の切片、特定農場の実測値ではない。画面にも「基準受胎率40%：仮定」と表示する。

元論文の個体・年・精液・産次・授精者のランダム効果をここで復元しない。原研究の個体別予測を再現するのではなく、共通の仮想基準に固定効果だけを移した参照計算とする。[S1のモデル形式を基にしたアプリ側の追加仮定]

### 4.2 計算

```text
R = OR(P1,category1) * ... * OR(P5,category5)
p_reference = p0*R / (1-p0+p0*R)
```

これはロジット加算モデルをオッズへ変換した代数計算である。`p0*R`をそのまま確率にしない。期間ごとの係数は当該期間として推定されたものなので、日数を追加で掛けたり日数乗したりしない。

`R`も出力し、絶対率の仮定と文献の相対効果を区別する。各オッズ比の95%信頼区間を機械的に乗算して総合95%信頼区間にしない。係数間の共分散を取得・反映していないため、本案は点の参照値のみを出す。

### 4.3 計算例

全5期間で同じ代表気温・RH70%が続いたと仮定し、基準確率を40%とした結果。実際の地域・設備導入の予測ではない。

| 代表気温 | THI | 区分 | 合成オッズ比R | 参考受胎率 |
|---:|---:|---|---:|---:|
| 15℃ | 58.835 | 基準 | 1.000000 | 40.0% |
| 20℃ | 66.350 | 軽度 | 0.738242 | 33.0% |
| 22℃ | 69.356 | 中等度 | 0.496625 | 24.9% |
| 26℃ | 75.368 | 高暑熱 | 0.423904 | 22.0% |

例：高暑熱の場合

```text
R = 0.773 * 1.005 * 0.693 * 0.922 * 0.854
  = 0.4239040657836599
p = 0.4*R / (0.6+0.4*R)
  = 0.22033534484527012
```

26℃/70%と22℃/70%という二つの仮想期間条件の差は約+2.84ポイント。26℃から22℃へ一時的に下げればその日の受胎率がこれだけ回復する、という意味ではない。また、湿度も設備により変化するため、これは同じ実設備の対策前後を計算した例ではない。

## 5. 時間の仕様：既存60分モデルは変更しない

熱モデルv0.5・決定v0.6は固定気象60分のままとする。[P1][P2]

受胎側の入力は、別の「授精前後の代表環境シナリオ」とする。初期UIは、全期間共通の代表気温・湿度を選び、「この条件が授精21日前〜30日後まで続いたと仮定」を明示して比較する。詳細で5期間別の区分／平均THIを入力することは可能だが、初版UIの必須機能ではない。

60分の計算結果しかない場合、5期間の曝露条件は不明である。これを黙って52日へ拡張しない。参照計算用に期間の条件として採用する操作は、`exposure_assumed=true`という追加仮定として結果・保存データに記録する。こうした仮定を許可しないモードでは受胎値をnullにし、熱の結果は継続表示する。

気象API、52日間の秒単位シミュレーション、卵胞・胚の動的モデル、実農場測定は追加しない。過去／未来を実際に観測したことにも、将来の天気を予報したことにもしない。

## 6. 牛舎・設備との接続範囲

この採用案は気温・湿度からTHI区分を参照する経路に限定する。設備の計算結果を期間代表条件として使う場合は、気温と湿度を必ず対で使う。ミスト後だけRHを元に戻す処理や、屋根対策後の相対湿度を無条件で固定する処理はしない。[P1]

原研究の屋外観測所THIを牛位置のモデル温湿度へ置き換えるのは、追加の適用仮定である。既定表示は「受胎率シナリオ／気温・湿度区分の参照値」とし、設備による総合的な受胎率改善保証とは表示しない。[S1]

循環ファンやソーカーによる直接冷却、放射熱低減の全量を本モデルに上乗せしない。放熱改善W、送風体感温度、固定表面温度35℃を、この式のTHIや深部体温に読み替えない。これはv0.5・v0.6の表示境界を維持するもので、新しい未決課題を増やすものではない。[P1][P2]

同じTHI区分なら受胎の参照値は変わらない。UIは「同じ参照区分」と表示し、「設備に効果なし」とは評価しない。熱・風・放熱の結果は別に更新する。

## 7. 入出力・状態と対象外

入力：モデル版、5期間のTHI区分または平均THI、仮想基準受胎率p0、人工授精を対象とすること、期間条件の由来・仮定。

出力：区分と参照した各OR、合成R、参考確率、p0、状態、根拠・仮定。比較は同一p0・同一モデル版でのみ行い、差はパーセントポイントで表示する。

| 状態 | 例 | 出力 |
|---|---|---|
| available_reference | 5期間の掲載区分が決まり、p0が有効 | 参考確率・R・入力の由来 |
| out_of_scope | 期間不明、人工授精以外、未知の区分、未承認の短期→期間拡張 | 確率null、理由、熱計算は継続 |
| invalid_input | 非有限値、p0が0以下/1以上、RHが0〜100%外 | 確率null、入力エラー |

肉用牛、別品種、自然交配、胚移植への流用、未経産牛専用の予測、流産率・分娩率・21日妊娠率への変換は本案の対象外。牛群の妊娠頭数や経営効果も今回の入力だけでは出さない。

## 8. 実装ファイルと検証

同梱する独立計算はPython 3.10以降・標準ライブラリのみ。

```sh
python fertility_reference.py
python -m unittest -v
```

- `reference_profile.json`：出典、区分、期間、OR、モデルの仮定。
- `fertility_reference.py`：THI・区分参照・オッズから確率への変換。
- `calculation_examples.json`：実際に実行した4ケース。
- `test_fertility_reference.py`：20件の単体テスト。
- `test_results.txt`：今回の実行記録。

20件すべて合格。区分境界、確率変換、欠損／対象外、52日の区間整合、掲載係数の保持、再現性、短期試行の自動外挿をしないことを確認した。科学的妥当性、外部農場での精度、3D、ブラウザ、既存コードとの統合を検証したものではない。

研究データを再学習したり、原モデルの切片・ランダム効果・標準誤差を復元したりしていない。ユーザーのLibraryや既存仕様を上書きしていない。
