# Cooling Planner：遮熱モデルと乳量参照表示の課題

評価日：2026-09-27。対象：v0.8の計算モデルと乳量参照。

状態：調査結果と改善候補。計算仕様の変更や補間の採用を承認済みとする文書ではない。
別エージェントが作業中のThree.js表示変更は対象外とする。

## 1. 評価の要点

遮熱・断熱・散水の作用を理解し、同じ仮定で案を比較する縮約モデルとしては整合している。
実牛舎の温度低下、乳量改善、投資回収を確定するための検証は不足している。

乳量参照は出典にない数値を生成しない設計だが、連続的に変化するシミュレーション条件と、
離散的な掲載6条件の組み合わせにより、通常操作では参照値が表示されにくい。
出典の値を守ることと、条件不一致時に判断材料を残すことは両立できる。

## 2. 維持したい設計

- 遮熱は日射反射率、断熱は材料熱抵抗、屋根散水は蒸発潜熱として区別する。
- 屋根の放射負荷を全量そのまま空気温度へ加えない。
- 複数対策の温度低下を単純に足し合わせない。
- 散水は供給・蒸発・流出・残水を区別する。
- 循環ファンの風速と、外気との空気交換量を区別する。
- 放熱Wを乳量、THI、深部体温の変化へ直接換算しない。

実装：`src/model/roof.ts`、`physics.ts`、`simulation.ts`。
仕様：`reference/thermal/MODEL.md`。

## 3. 遮熱モデルの課題

| ID | 確認した事実 | 利用者への影響 | 改善候補 |
|---|---|---|---|
| H01 | 換気量は標準で床面積あたり0.015 m³/s/m²。開口・外風から推定しない | 遮熱後の気温低下が換気の仮定に左右される | 換気条件を変えた感度比較。実測で校正するときの優先項目にする |
| H02 | 牛から屋根への形態係数は全地点0.35、屋根温度・平均放射温度も共通 | 屋根由来の放射の場所差は評価できない | 共通の代表放射条件であることを明示。位置依存化は別のモデル変更として検討 |
| H03 | 低値・基準・高値のプロファイルで屋根係数、反射率、換気量、形態係数を変えていない | 既存の放熱差の幅は、遮熱モデル全体の不確かさではない | 屋根側の感度を追加し、統計的な信頼区間と区別する |
| H04 | 屋根・空気の蓄熱を省略し、各時刻で準定常解を求める | 60分表示でも、屋根材が徐々に冷える応答や夕方の残熱は予測できない | 水膜の時間変化と建物の温度応答を区別して説明する |
| H05 | 外側長波放射は外気温基準の固定線形係数。塗装で変えるのは日射反射率 | 放射率の異なる材料、低放射率シート、夜間冷却の比較には不足 | 製品比較を対象にする場合に限り、放射率・天空条件・材料条件を追加検討 |

H01〜H05は主にモデルの適用範囲と仮定の課題であり、直ちにプログラムのバグを意味しない。
壁・床は外気温と同じ固定放射境界で、代表牛の熱・湿気は牛舎全体へ戻さない。
建物と全牛群を含む閉じた熱・水分収支を解くモデルではない。

### 感度確認

Python参照実装で、外気32℃・RH70%・屋根面日射800W/m²・牛位置風速2m/s、
散水とミストなし、反射率0.20から0.70への変更を比較した。
下記は実測範囲ではなく、今回の評価用に仮定を変えた結果である。
乾燥・一定条件のため60秒計算でも同じ準定常値となる。アプリの全地点計算値とは区別する。

| 標準に対する換気量 | 対策前の気温 | 遮熱後の気温 | 放熱改善 |
|---|---:|---:|---:|
| 0.5倍 | 39.9℃ | 35.6℃ | 367W |
| 1倍 | 36.5℃ | 34.0℃ | 285W |
| 2倍 | 34.4℃ | 33.1℃ | 236W |
| 4倍 | 33.2℃ | 32.6℃ | 209W |

標準換気量のまま形態係数だけを0.15、0.35、0.55へ変えると、放熱改善は約180、285、391W。
これらの係数範囲を実農場の代表範囲として採用したものではない。

再現には `reference/thermal` で次を実行する。

```sh
python3 -B - <<'PY'
from dataclasses import replace
from thermal_model import Model, Scenario, simulate
m = Model()
s = Scenario('base')
cases = [(f'ventilation x{f}', replace(m,
    ventilation_m3s_per_floor_m2=m.ventilation_m3s_per_floor_m2*f))
    for f in (0.5, 1, 2, 4)]
cases += [(f'view factor {f}', replace(m, cow_roof_view_factor=f))
          for f in (0.15, 0.35, 0.55)]
for label, model in cases:
    a = simulate(model, s, 60)
    b = simulate(model, replace(s, reflectance=0.7), 60)
    print(label, a['local_air_c'], b['local_air_c'],
          b['q_net_cooling_w'] - a['q_net_cooling_w'])
PY
```

## 4. 乳量参照表示の課題

実装：`src/model/references.ts` の `MILK_ROWS` と `milkReference`。

| 気温 | 風速0.18m/s | 風速2.24m/s | 風速4.02m/s |
|---|---:|---:|---:|
| 27℃ | 85% | 95% | 95% |
| 35℃ | 63% | 79% | 79% |

上表はコードに転記された掲載値。適用湿度は60〜70%、時間変動しない条件のみ。
気温・風速の一致判定は許容差1e-9であり、表示上丸めた値の一致ではない。
基準乳量がある場合は、その値に掲載比率を掛けてkg/日を計算する。
今回、元資料の原表を再照合したものではない。

### M01：通常操作と完全一致条件がかみ合わない

屋根対策・ファン配置を変えると気温と風速が連続的に変わるが、参照条件は離散的である。
湿度範囲や静的条件もあるため、条件変更後に `out_of_scope` となりやすい。
現状も対象外の理由や掲載条件を見る導線は存在する。課題は表示が完全に空であることではなく、
「自分の条件と掲載条件をどう比較するか」が弱いことである。

### M02：補間だけでは設備全体の乳量効果を表せない

表の参照は気温・風速等に限定される。平均放射温度や牛体散水による放熱改善を直接扱わない。
連続した乳量値を表示しても、遮熱・断熱・散水を含む設備の総合効果を予測できるとは限らない。
参照値と実測乳量、予測乳量、設備導入による増分を混同させないことが必要である。

### 改善候補（未実装）

1. 条件一致時は、現在どおり掲載値・条件・出典を表示する。
2. 不一致時も、現在条件と掲載6条件を比較できる表示を残す。
3. 掲載範囲の内外、湿度条件、時間変動による対象外理由を分けて説明する。
4. 近傍条件を強調する場合は、気温と風速の違いを個別に示す。異なる単位を根拠なく足して「最も近い」と判定しない。
5. 補間は別途、元資料・適用軸・範囲・検証方法を確認して判断する。現行の補間禁止は今回変更しない。

表示例：

> この条件の乳量値は資料にありません。比較用に掲載条件を示します。現在の牛舎の予測値ではありません。

補間を将来採用する場合も、掲載値・補間推定・範囲外を区別し、外挿や放熱Wからの換算を自動的に認めない。

### 改善後に確認すること

- 設備の微小な変更でも掲載表と現在条件の比較が失われない。
- 湿度範囲外・時間変動・気温風速不一致の理由が分かる。
- 掲載6条件の値と既存の適用判定を変えない。
- 参考表の値を現在地点の予測値として表示しない。
- 「乳量が出ない＝設備効果がない」と読める表示にしない。
