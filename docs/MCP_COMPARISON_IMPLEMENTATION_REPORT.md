# MCP案の画面復元と残る不足の比較

更新：2026-10-01。ユーザー依頼の①文書・JSON受け渡し、②悪い場所・不足が残る場所の表示を実装。

## 変更

- MCPの`evaluate`応答全体または`project`を、JSONファイルと貼付で読み込める。配置・共通気象・係数・基準案を既存Storeへ復元し、画面で再計算する。既存のschema 9・2MiB上限・入力検証・Undoを利用する。
- ローカルMCPの`evaluate`も編集後の`project`を返す。リモートMCPと共用する集計には`comparison`と区域別の不足低減・残る地点の診断を追加した。新しいMCPツールや保存サービスは追加していない。
- 案比較は平均・最大放熱不足、牛床／採食／待機の不足、残る不足・基準より減らない地点数、水・電力と基準差を表示。乳量・受胎・運転費は参考影響タブで保持する。
- 不足上位3地点のボタンから、床の不足表示と選択地点の放熱内訳・基準差を確認できる。対流・放射が負の場合や流出水も既存結果から表示する。
- 現在計画・乳量仕様・作業規約・READMEの古い「未実装」記述を整理した。過去の受入調査は当時の履歴として区別する。
- ハッカソンPOCとして、エージェントは型チェック・関連テスト・ビルドを担当し、E2Eは人間とCIが担当する方針をAGENTS.mdとREADMEへ記載。

レイアウト本体`src/ui/layout.ts`・`src/styles.css`は今回編集していない。表示内容・読込ダイアログは別モジュールへ置いた。共有作業中に別担当のコミットが進んだため、本変更の一部はそのコミットに含まれている。ソースを巻き戻さず、最新の共有内容から配布物を生成する。

## 仮定と制限

熱・水・乳量・受胎の物理式と係数は変更していない。追加したのは既存結果の表示集計。

- 平均は70代表点の単純平均、最大は地点ごとの60分平均不足の最大。瞬間最大・牛群の滞在時間加重とは異なる。
- 不足低減は「基準案の不足−選択案の不足」。不足が残り、低減が数値ゼロ以下の地点を「減らず残る」とする。既存診断と同じ`1e-6 W`の数値誤差ガードを使い、健康・安全の閾値は追加していない。
- 「局所作用なし」は送風・牛体散水・ミストの作用診断で、屋根効果は含まない。屋根で改善していても不足が残る場合があり、改善の有無と別に表示する。
- 放熱・場所は固定気象60分、資源・乳量は別の評価日24時間。夜間の日射変化は未実装。日全体の最適化や現場での妥当性を保証しない。
- 制約付き探索・共有リンクは後続。公開AWS版への反映・実環境の照合は今回実施していない。

### 人間／CIの簡単な確認

1. 「案比較」→「MCP案のJSONを読込」に案JSONを貼付し、配置・条件の反映と「戻す」を確認する。
2. 平均・最大不足と水・電力を確認し、不足上位の地点を押して場所・放熱内訳の切替を確認する。

専用E2Eは`tests/e2e/test_mcp_comparison.py`の2件。実行する場合はREADMEの人間／CI向け手順を使う。
