# Cooling Planner — 現在の開発計画

更新日：2026-10-01。
状態：ユーザーが明示した現在の目的・対象範囲を整理した正本。
本書は計画・計算仕様の変更を記録する。アプリの実装開始や実行コードの変更を承認するものではない。
ユーザーから実装依頼があるまでは、調査・計画・依頼された文書修正を行う。

## 1. 目的

牛舎の暑熱対策を、設備を置き換えながら比較できる、シミュレーションゲームに近い可視化ツールにする。

対象は `cooling-planner/`。まずはフリーストール牛舎1種類に絞る。
実農場ごとの完全再現は狙わない。

以前の30秒投資スクリーニングから目的を変更した。
4項目入力、ファン不足台数、投資回収、見積依頼、30秒での理解は、現在の完成条件ではない。

## 2. 操作と比較

遮熱、断熱、屋根散水、ファン、ソーカー、ミストを追加・配置・変更できるようにする。
屋根全体へ適用する対策と、位置・向き等を操作する設備について、具体的な操作の対応は今後の受入条件で整理する。

基準案と改善案を同じ気象条件で比較し、どこがどれだけ変わったかを見る。
牛舎と設備操作を中心に、条件変更から結果の変化を追える体験を目指す。

## 3. 見せたい因果と出力

```text
設備 → 牛舎環境 → 牛の熱負荷 → 乳量・受胎への参考影響
```

| 段階 | 見せるもの |
|---|---|
| 牛舎環境・資源量 | 屋根裏温度、舎内気温、放射環境、風速、湿度、水使用量、電力量 |
| 牛の熱負荷 | 送風による体感温度、放熱改善量など |
| 乳量 | 暑熱負荷を日単位で集計する仮説モデルによる日乳量・基準案との差 |
| 受胎 | 論文のTHI区分と授精前後の期間別影響による参考シナリオ |

乳量は[暑熱負荷→乳量モデルv0.1](MILK_HEAT_MODEL_V0_1.md)を採用済み。比較の主役は放熱不足・場所・水・電力で、乳量・受胎は参考影響として表示する。
全設備の作用を既存の熱計算へ集約し、放熱不足の日平均から乳量の参考影響へつなぐ。
係数・滞在割合・時間の遅れは明示的な仮定。受胎は従来の参考シナリオを維持する。
乳量仮説モデルは実装済み。日運転を含む代表日計算を行い、掲載6条件表は資料として残す。実装・検証の対応は[乳量実装報告](MILK_MODEL_IMPLEMENTATION_REPORT.md)を参照する。実牛舎での妥当性は未検証。

## 4. 計算と表示の境界

- モデルが不完全でも、仮定を明示してまず全体を動かす。
- 同じ検証済み入力は同じ数値結果を返す。数値は決定論的な計算から取得する。
- 乳量はモデルv0.1の式・初期係数・上限・時間単位に従う。文献値と仮定を区別し、実農場の精度保証と扱わない。
- 既存の掲載6条件表は原資料として保持する。表自体の補間・外挿は行わず、新モデルと混同しない。
- 受胎は参考シナリオとして表示し、実際の牛群の受胎率予測と扱わない。
- 放熱から乳量への接続はモデルv0.1に定義した仮説式に限る。WからTHI・受胎への換算は追加しない。送風体感温度と環境のTHIも区別する。
- 比較の基準設備、共通気象、評価地点、平均値と時刻別値の違いを明示する。
- 現行の60分熱計算は既存実装の仕様。乳量仮説モデルでは固定気象・日射の24時間準備計算と24時間評価を実装し、代表日・運転・滞在分布の仮定を明示する。
- 本更新は計算仕様と計画の変更であり、コード・係数の実装・配布物は変更しない。

## 5. 現時点の対象外

- 実牛舎での計測・モデル検証。別フェーズで扱い、現在の完成条件へ追加しない。
- 実農場ごとの完全再現、複数の牛舎形式への拡張。
- 実牛舎の精密な乳量予測、年間乳量への自動外挿。全設備から受胎への新たな換算。
- 設備切替後の乳量時系列画面は後続拡張。初版は同じ代表日が続く場合の比較。
- 投資回収、見積依頼、投資時期の推薦、本格Choice Horizon。
- CFD、実時間IoT、認証・課金など、現在の目的に明記していない機能の追加。

## 8. MCP案の画面復元と残る不足の比較（2026-10-01）

ユーザー依頼により、文書と実装の整合、MCP案のJSON復元、悪い場所・不足が残る場所の比較を実装済み。
MCPのevaluate応答全体またはprojectを読込・貼付し、既存の検証を通して画面で再計算する。
案比較では70代表点の平均・最大不足、牛床・採食・待機の区域別不足、基準より不足が減っていない地点数、水・電力量を併記する。
最大不足は地点ごとの60分平均の最大、単純平均は牛群の頭数・滞在時間加重ではない。
「局所作用なし」は屋根効果を含まない作用診断であり、不足の残存・改善の有無とは別に示す。
乳量・受胎は参考影響として保持する。熱・水・乳量・受胎の物理式と係数は変更しない。
実装・今回の検証は[MCP案復元と比較の報告](MCP_COMPARISON_IMPLEMENTATION_REPORT.md)を参照する。

制約付き自動探索・共有リンク・時刻別気象・ソーカー由来湿度のフィードバック・現場測定との比較は後続候補で、今回の実装範囲には含めない。
現在の固定気象60分の放熱診断と評価日24時間の資源量を混同せず、日全体の最適化を完了したとは扱わない。
