# リアル3D表示 — 実装記録

日付：2026-09-29。

## 変更

既存の描画を「標準3D」に残し、「リアル3D」「2D」と切り替えられるようにした。
3つの表示は同じProjectStore、設備配置、選択地点、Worker結果、Undoを使う。
初期表示は従来の標準3D。別の牛舎モデルや別の計算結果を作らない。

| 対象 | リアル3Dの内容 |
|---|---|
| 牛舎 | コンクリート床、目地、牛床と柵、鋼材の柱・トラス、採食柵、管理室、搾乳設備、片側の屋根 |
| 牛 | 立位と休息姿勢を区画ごとに固定して混在。胴体・後躯・首・頭に共通の斑模様。立位には4本の脚と蹄 |
| 材質と光 | StandardMaterial、環境反射、空と地面の補助光、日光、接地影、ACES、sRGB |
| カメラ | 既存の回転・拡大・平行移動・全体/上面/側面プリセットを共有 |
| ファン | ガード、リング、羽根、モーター、支持部。位置・向き・径に追従 |
| 風 | 向きと広がりを示す移動する筋。風速の減衰、稼働時間、障害物、表示ON/OFFに連動 |
| ソーカー | ノズルの向きと噴霧角から水滴の筋を表示 |
| ミスト | 柔らかい半透明粒子。ソーカーと形状で区別 |
| ヒートマップ | 切替で既存の指標・色目盛りを床へ重ねる。無効地点は灰色と斜線 |
| 分析表示 | 牛と屋根を隠し、ヒートマップを表示 |
| マウス配置 | 既存の設備選択・ドラッグ・Escape・Undoを利用 |

風と水の運転状態は既存60分表示の時刻を使用する。日乳量の24時間運転とは区別する。
粒子の動きは表示専用の時計で動き、計算時刻・保存入力・熱収支は変えない。
端末の「動きを減らす」設定では粒子を静止表示にし、非表示タブでは描画更新を休止する。

## 見た目の評価と限界

付属の3つの基準画像を見て、ゲーム用の10項目を牛舎シミュレータの役割へ読み替えて評価した。
0=未確認/仮置き、1=基本表示、2=造形・材質を整えた表示、3=展示品質。
これは作業者による主観評価で、実写との一致や第三者評価ではない。

| 項目（このアプリでの対象） | 標準 | リアル | 根拠・残件 |
|---|---:|---:|---|
| 方向性（牛舎らしさ） | 1 | 2 | 実用構造と材質の役割が読み取れる |
| 主役（牛・ファン） | 1 | 1.5 | 部位とガードを追加。牛の解剖形状・毛並みは簡略 |
| 制約対象（管理室・柵・柱） | 1 | 2 | 太さ・構造・材質を表示 |
| 操作対象（選択と設備配置） | 2 | 2 | 同じマウス操作・Undo、選択リング |
| 環境（床・構造・採食帯） | 1 | 2 | 柱・トラス・柵・床目地・屋根 |
| 材質 | 1 | 1.5 | PBRと生成模様。高解像度の実素材は未使用 |
| 照明 | 1 | 2 | 日光、環境反射、影、色管理 |
| 動き（風・水） | 1 | 2 | 方向を追える筋と水滴、運転状態に追従 |
| UI | 2 | 2 | 同じ比較画面に表示切替を追加。ゲームHUDには変更しない |
| 描画の検証 | 1 | 2 | 指標と複数画面、動き、実操作の証跡。実機GPUは未測定 |

平均は標準1.2、リアル1.9。スキルのPremium/Showcase合格を主張するものではない。
次に実写寄りへ進めるには、寸法・権利が確認できる牛・設備のモデルと実素材テクスチャが必要。
今回の「リアル3D」はコードによる造形・材質・光の改善であり、写真同等の再現ではない。

風の筋はファン軸に沿う模式的な軌道。既存のfanContribution・障害物判定を使うが、
乱流・循環流・複数ファンの合成流線を解いていない。牛・柵・トラスは表示用で、物理障害物を増やしていない。
水滴・霧の粒子数、動く速度、消失位置は見やすさのための表現で、水量を表す粒子積分ではない。

## 牛の表示修正（2026-09-29）

後躯に白一色の材質を使っていた点を修正し、胴体と同じ斑模様を適用した。
テクスチャのランダム配置で背中側が白く残る偏りも修正し、各UV領域に大きな斑を分散した。
全頭同じ休息姿勢だった表示を、立位と休息の混在に変更した。姿勢は区画から決定し、
再描画や案切替でランダムに変わらない。立位の脚・蹄・尾と頭の位置も合わせた。
姿勢割合は見た目のための仮定で、牛の行動予測や計算地点・放熱モデルには反映しない。

牛表示修正後も型チェック・131テスト・ビルド、ブラウザでの拡大表示と計算hash不変を確認。
立位追加後の設備ドラッグ・Undo・風と散水のブラウザ試験（E26/E27）も成功。

## ホルスタインの造形と採食帯への移動（2026-09-29）

- `src/views/holstein.ts`に胴体の断面形状を追加。肩、肋腹、腰、後躯で太さを変え、背中を平らに寄せた。
- 首と細長い顔、白い額の模様、鼻先・鼻孔、耳と耳標を追加。
- 前脚と後脚で関節位置を変え、蹄を左右に分割。乳房・乳頭・尾も造形した。
- 小さな模様の繰り返しを、大きな不規則な斑模様へ変更。3種類の共通材質を個体ごとに使い分ける。
- 牛床の3頭を採食帯へ移し、頭を下げる採食姿勢にした。表示頭数は50頭（牛床47、採食帯3）。
- 頭数・姿勢は表示用。空いた牛床も計算地点として残し、牛の移動・滞在分布・障害物・放熱の計算は変更しない。
- 描画診断にcowPosesを追加し、ブラウザ試験E26で採食3頭・合計50頭・立位と休息の混在を確認する。

造形はコードで作った簡略モデル。写真測量や実牛の寸法計測に基づくモデルではない。

今回の造形変更後、型チェック・131テスト・ビルド、E26/E27のブラウザ試験が成功。
表示内訳は立位25頭・休息22頭・採食3頭。拡大画像は`evidence/realistic/cows-closeup.png`。
横・前・後ろの近接画像を`evidence/realistic/holstein-{side,front,rear}.png`に保存して確認した。
近接時の描画は約30.3万三角形（風・水表示OFF）。初回より細部が増えており、
モバイルの30万という目安を約1%超えるが、胴体の輪郭を維持するため今回は許容した。実機GPU性能は未検証。
